Hallo kenalin nama saya Gabriel Silitonga. Saya Sangat senang bermain game, terutama game mobile legend. saya sudah bermain game ini sejak tahun 2018. saya sangat suka bermain game ini karena banyak hero yang bisa di mainkan dan juga banyak skin yang bisa di beli. saya juga suka bermain game ini karena bisa bermain bersama teman-teman saya. Yang paling saya suka dari game ini adalah bisa bermain bersama teman-teman saya karena bisa saling membantu untuk mencapai kemenangan. saat ini fokus saya adalah untuk mencapai rank mythic glory. Awalnya rank saya adalah epic, kemudian saya naik ke legend, lalu saya naik ke mythic." Sekarang saya sedang berusaha untuk mencapai mythic glory. tapi untuk mencapai rank tersebut tidaklah gampang. Karena saya harus menghadapi para darksistem yang selalu membuat saya kesal dalam menghadapinya yang dimana saya selalu toxic dan marah-marah karena kalah. tapi itu karena saya main solo makanya susah tapi setelah saya masuk party dengan teman-teman saya musuhnya menjadi lebih mudah untuk di kalahkan karena tidak ada para darksistem. saya sama teman-teman saya bantai-bantai lawan sampai gak bernapas hingga rata dan salah satu temanku ada yang montage dapat lima musuh dan satu temanku dapat savage. hingga saya mencapai rank mythic glory bintang 70.
